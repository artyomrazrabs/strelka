# Стрелка

Приложение для вызовов на соревнование: забей стрелку, прими вызов, выясни, кто лучше.

## Что умеет первая версия

- вход по ссылке на почту, выбор ника;
- забить стрелку: игроку по нику, по ссылке (почта, соцсети) или открытый вызов для всех;
- принять, отказаться или предложить свои условия; автор принимает или отклоняет правки;
- оба отмечают результат: совпало — засчитано, не совпало — конфликт;
- лента открытых стрелок с поиском по категориям;
- статистика: победы, поражения, серия, по дисциплинам, история.

## Как устроено

Обычный сайт без сборки: `index.html`, `styles.css` и папка `js/`.
Данные и вход — Supabase, хостинг — Vercel.

- `supabase/schema.sql` — таблицы и правила доступа. Запускается один раз в Supabase → SQL Editor.
- `js/config.js` — адрес проекта Supabase и публичный ключ.

## Настройка Supabase

1. Создай проект, открой SQL Editor, вставь `supabase/schema.sql`, нажми Run.
2. Authentication → URL Configuration: в Site URL и Redirect URLs впиши адрес сайта на Vercel.
3. Скопируй Project URL и публичный ключ (anon / publishable) в `js/config.js`.

Встроенная почта Supabase отправляет мало писем в час — для теста с друзьями хватит.
